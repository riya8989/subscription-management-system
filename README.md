# subscription-management-system
Developed a Subscription Management System using PHP, MySQL, HTML and CSS. Users can register, log in and subscribe to plans, while the admin panel lets the admin manage users, plans and subscriptions. All data is stored in a MySQL database. The project runs locally on XAMPP, and the source code is available on GitHub.
# Subscription Management System

PHP and MySQL web application for managing user subscriptions.

## How to run
1. Install XAMPP and start Apache and MySQL.
2. Copy this project folder into xampp/htdocs.
3. Open phpMyAdmin, create a database, and import the .sql file.
4. Open http://localhost/bill/ in your browser.

## Features
- User registration and login
- Plan selection
- Admin panel
